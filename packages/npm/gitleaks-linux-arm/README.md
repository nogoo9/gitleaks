# @nogoo9/gitleaks-linux-arm

This is the **linux/arm** binary package for [`@nogoo9/gitleaks`](https://www.npmjs.com/package/@nogoo9/gitleaks).

Install `@nogoo9/gitleaks` instead — it picks this package automatically for your platform via `optionalDependencies`.

```bash
npm install @nogoo9/gitleaks
```
